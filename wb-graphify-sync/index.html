WB GRAPHIFY SYNC

Рабочие материалы и проверка результатов

Приложение владельца для работы с Google-документами через выбранного ИИ-помощника и отдельной проверки материалов системы мотивации.

Работа с Google по поручению владельца

Локальные подключения помогают найти и прочитать нужные файлы, проанализировать документы и таблицы, сохранить согласованный результат и обновить существующий объект по прежнему адресу.

По отдельному поручению доступны загрузка файлов, импорт документов и таблиц, а также работа с кодом и запуск разрешённых Google Apps Script. Аккаунт и рабочая папка выбираются настройкой соответствующего проекта.

Выбранные материалы и ответы инструментов могут входить в контекст текущего чата с OpenAI или Anthropic. Выбор помощника и конкретное поручение определяют обработку; каждый документ не отправляется автоматически обоим сервисам.

Проверка материалов мотивации

  1. Владелец отдельно подключает Google к серверному компоненту с двумя правами только на чтение.
  2. В реестре согласуются источник, лист, диапазон, версия материала и рабочая задача.
  3. После отдельного разрешения выбранный пакет передаётся OpenAI для предварительного разбора.
  4. Итоговую приёмку выполняет человек. Ответ модели сам по себе не закрывает задачу и не разрешает выплату.

Google-разрешения шире выбранного материала. Ограничение конкретными источниками задаётся приложением. Два права только на чтение относятся к этому компоненту; другие локальные функции приложения могут изменять Google-документы по поручению.
